# 千问模型配置说明

## 📋 模型选择指南

### 文本对话模型（推荐用于问答系统）

#### 1. qwen-turbo ⚡
- **特点**：快速响应，成本较低
- **适用场景**：一般对话、快速问答
- **推荐度**：⭐⭐⭐⭐⭐

#### 2. qwen-plus ⚖️
- **特点**：平衡性能和效果
- **适用场景**：需要较好效果的对话
- **推荐度**：⭐⭐⭐⭐

#### 3. qwen-max 🚀
- **特点**：最强性能，效果最好
- **适用场景**：复杂推理、高质量回答
- **推荐度**：⭐⭐⭐⭐⭐（如果预算允许）

#### 4. qwen2.5-7b-instruct 🎯
- **特点**：7B参数，支持微调
- **适用场景**：需要针对特定领域微调
- **推荐度**：⭐⭐⭐⭐（如需微调）

#### 5. qwen2.5-14b-instruct 🎯
- **特点**：14B参数，支持微调，效果更好
- **适用场景**：需要高质量微调模型
- **推荐度**：⭐⭐⭐⭐⭐（如需微调）

#### 6. qwen2.5-32b-instruct / qwen2.5-72b-instruct
- **特点**：超大参数，最强效果
- **适用场景**：对效果要求极高的场景
- **推荐度**：⭐⭐⭐（成本较高）

### ⚠️ 不推荐的模型

#### qwen2.5-vl / qwen-vl
- **类型**：视觉语言模型
- **用途**：图像理解、多模态任务
- **不适用**：纯文本问答（需要图像输入）

#### qwen2.5-vl-embedding
- **类型**：嵌入模型
- **用途**：文本向量化、相似度计算
- **不适用**：对话生成（只能生成向量，不能生成文本）

## 🔧 配置方法

### 在 config.py 中修改

```python
QWEN_API_CONFIG = {
    "api_key": "your-qwen-api-key",
    "base_url": "https://dashscope.aliyuncs.com/compatible-mode/v1",
    "model": "qwen-turbo",  # 修改这里
    "temperature": 0.7,
    "max_tokens": 2000
}
```

### 推荐配置

#### 开发测试
```python
"model": "qwen-turbo"  # 快速、便宜
```

#### 生产环境
```python
"model": "qwen-plus"  # 或 "qwen-max"
```

#### 需要微调
```python
"model": "qwen2.5-14b-instruct"  # 支持微调，效果好
```

## 🎯 微调说明

如果您想使用 qwen2.5 系列模型进行微调：

1. **选择模型**：推荐 `qwen2.5-14b-instruct` 或 `qwen2.5-7b-instruct`
2. **准备数据**：准备中医领域的中文问答数据
3. **微调方式**：
   - 使用阿里云DashScope平台进行微调
   - 或使用本地部署的模型进行微调
4. **使用微调模型**：
   - 如果通过API使用，微调后会有新的模型ID
   - 将模型ID配置到 `config.py` 中

## 📝 注意事项

1. **API密钥**：确保已配置有效的API密钥
2. **模型可用性**：某些模型可能在某些区域不可用
3. **成本考虑**：qwen-max 和 qwen2.5-72b 成本较高
4. **响应速度**：参数越大的模型响应越慢

## 🔍 当前配置检查

访问 `/api/health` 接口可以查看当前配置：
- `qwen_model`: 当前使用的模型
- `qwen_api_key_configured`: API密钥是否已配置

## ❓ 常见问题

### Q: 为什么显示 qwen-turbo 但配置是 qwen2.5-vl-embedding？
A: 可能是代码中有默认值覆盖，或者配置未正确加载。检查 `config.py` 中的配置。

### Q: 可以使用 qwen2.5-vl 吗？
A: 不推荐。qwen2.5-vl 是视觉语言模型，需要图像输入，不适合纯文本问答。

### Q: 如何知道模型是否支持？
A: 系统启动时会显示警告信息，如果模型不适合会提示。

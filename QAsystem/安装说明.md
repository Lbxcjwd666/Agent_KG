# 安装说明

## 🔧 后端依赖安装

### 方式1：使用requirements.txt（推荐）

```bash
cd smart-qa-system
pip install -r requirements.txt
```

### 方式2：手动安装

```bash
pip install flask==3.0.0
pip install flask-cors==4.0.0
pip install neo4j==5.15.0
pip install requests==2.31.0
pip install python-dotenv==1.0.0
```

## 📦 依赖说明

### flask-cors
**作用**：解决前后端跨域问题（CORS - Cross-Origin Resource Sharing）

**为什么需要**：
- 前端React应用运行在 `http://localhost:3000`
- 后端Flask应用运行在 `http://localhost:5000`
- 浏览器安全策略不允许不同端口的跨域请求
- flask-cors会自动添加必要的HTTP头来允许跨域请求

**如果未安装**：
- 系统会自动使用手动CORS处理（备选方案）
- 但建议安装flask-cors以获得更好的功能和性能

## ✅ 验证安装

运行以下命令验证依赖是否安装成功：

```bash
python -c "import flask; import flask_cors; import neo4j; import requests; print('所有依赖已安装')"
```

## 🐛 常见问题

### 1. flask-cors未解析引用
**原因**：IDE可能没有识别到已安装的包

**解决方案**：
1. 确认已运行 `pip install flask-cors`
2. 检查Python解释器路径是否正确
3. 重启IDE
4. 如果仍有问题，代码已包含备选方案，可以正常运行

### 2. 导入错误
**错误信息**：`ModuleNotFoundError: No module named 'flask_cors'`

**解决方案**：
```bash
pip install flask-cors
```

### 3. 跨域请求失败
**错误信息**：`Access to fetch at 'http://localhost:5000/api/chat' from origin 'http://localhost:3000' has been blocked by CORS policy`

**解决方案**：
1. 确认flask-cors已安装
2. 确认后端代码中已启用CORS
3. 检查后端是否正常运行

## 🔍 代码说明

代码已包含两种CORS处理方式：

1. **优先使用flask-cors**（如果已安装）
   - 功能更完善
   - 配置更灵活
   - 性能更好

2. **手动CORS处理**（备选方案）
   - 不依赖额外库
   - 基本功能可用
   - 适合快速测试

系统会自动检测并选择合适的方式。

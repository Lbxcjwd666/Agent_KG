# 问题修复说明

## 🔧 已修复的问题

### 1. 404 Not Found 错误 ✅

**问题原因**：
- Flask应用没有定义根路径 `/` 的路由
- 只有 `/api/*` 的路由，访问根路径时返回404

**解决方案**：
- 添加了根路径路由 `@app.route('/', methods=['GET'])`
- 返回API文档和系统信息
- 现在访问 `http://localhost:5000/` 会显示系统信息

**测试方法**：
```bash
# 访问根路径
curl http://localhost:5000/

# 或浏览器访问
http://localhost:5000/
```

### 2. 模型配置问题 ✅

**问题原因**：
- 配置文件中使用了 `qwen2.5-vl-embedding`（嵌入模型）
- 该模型不适合文本对话任务
- 用户想使用 `qwen2.5-vl` 进行微调，但这是视觉语言模型

**解决方案**：
1. **修正默认模型**：改为 `qwen-turbo`（适合文本对话）
2. **添加模型验证**：启动时检查模型是否适合
3. **提供模型说明**：在配置文件中添加详细注释
4. **创建模型配置文档**：说明各种模型的用途

**推荐的模型选择**：

#### 用于文本问答（推荐）
- `qwen-turbo` - 快速、便宜 ⭐⭐⭐⭐⭐
- `qwen-plus` - 平衡性能和效果 ⭐⭐⭐⭐
- `qwen-max` - 最强性能 ⭐⭐⭐⭐⭐

#### 用于微调（如果需要进行微调）
- `qwen2.5-7b-instruct` - 7B参数，支持微调
- `qwen2.5-14b-instruct` - 14B参数，效果更好 ⭐⭐⭐⭐⭐

#### 不推荐用于文本问答
- ❌ `qwen2.5-vl` - 视觉语言模型，需要图像输入
- ❌ `qwen2.5-vl-embedding` - 嵌入模型，只能生成向量

## 📝 配置修改

### 修改模型配置

编辑 `src/config.py`：

```python
QWEN_API_CONFIG = {
    "api_key": "your-qwen-api-key",  # 替换为您的API密钥
    "base_url": "https://dashscope.aliyuncs.com/compatible-mode/v1",
    "model": "qwen-turbo",  # 修改这里
    "temperature": 0.7,
    "max_tokens": 2000
}
```

### 如果需要使用微调模型

```python
"model": "qwen2.5-14b-instruct"  # 支持微调
```

## ❓ 常见问题

### Q: 为什么还是显示 qwen-turbo？
A: 检查 `config.py` 中的 `model` 配置，确保已保存。如果修改后仍显示旧值，重启Flask应用。

### Q: 可以使用 qwen2.5-vl 吗？
A: 不推荐。qwen2.5-vl 是视觉语言模型，需要图像输入，不适合纯文本问答。如果确实需要，需要修改代码支持图像输入。

### Q: 如何知道模型是否支持？
A: 启动时查看控制台输出，如果模型不适合会显示警告信息。

### Q: 404错误还存在吗？
A: 已修复。现在访问根路径会返回API文档信息。

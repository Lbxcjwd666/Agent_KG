# 知识图谱可视化和推理路径功能说明

## 🎯 功能概述

为smart-qa-system添加了知识图谱可视化和推理路径展示功能，增强系统的可解释性和可信性。

## 📋 修改的文件

### 1. 后端文件 (已存在，功能完整)

#### `src/app.py`
- **修改内容**: 增强了HTML模板，添加可视化功能的前端支持
- **新增功能**:
  - 知识图谱可视化显示
  - 推理路径步骤展示
  - 标签页切换功能
  - 响应式CSS样式

#### `src/kg_enhancer.py` (已存在)
- **功能**: 知识图谱查询和上下文格式化
- **API**: `query_relations()`, `format_kg_context()`

#### `src/qwen_api.py` (已存在)
- **功能**: 千问API调用，实体抽取和答案生成
- **API**: `extract_entities()`, `generate_answer()`

### 2. 前端文件 (React组件，已存在)

#### `src/QuestionAnswer.js`
- **修改内容**: 增强了数据处理逻辑
- **新增功能**:
  - 处理后端返回的可视化数据
  - 设置默认显示标签页
  - 支持知识图谱、推理路径的显示

#### `src/KnowledgeGraphVisualization.js` (已存在)
- **功能**: 知识图谱的SVG可视化组件
- **特性**: 节点交互、工具提示、图例

#### `src/ReasoningPathVisualization.js` (已存在)
- **功能**: 推理路径的步骤展示组件
- **特性**: 可折叠步骤、详细信息显示

### 3. 样式文件 (已存在)

#### `src/QuestionAnswer.css`
- **功能**: 主界面样式，包含可视化相关样式

#### `src/KnowledgeGraphVisualization.css`
- **功能**: 知识图谱可视化专用样式

#### `src/ReasoningPathVisualization.css`
- **功能**: 推理路径展示专用样式

### 4. 新增文件

#### `test_visualization.py`
- **功能**: 测试可视化功能的完整性
- **用途**: 验证模块导入和数据结构

#### `可视化功能说明.md` (本文件)
- **功能**: 详细说明修改内容和使用方法

## 🔧 功能特性

### 1. 知识图谱可视化
- **节点显示**: 查询实体和相关实体的可视化
- **关系展示**: 实体间关系的图形化表示
- **交互功能**: 节点点击、悬停提示
- **统计信息**: 节点数量、关系数量统计

### 2. 推理路径展示
- **步骤分解**: 将推理过程分解为清晰的步骤
- **详细信息**: 每个步骤的具体操作和结果
- **可折叠界面**: 支持展开/折叠详细信息
- **进度指示**: 清晰的步骤编号和进度显示

### 3. 标签页界面
- **多标签切换**: 知识图谱信息、图谱可视化、推理路径
- **智能默认**: 根据数据可用性自动选择默认标签
- **响应式设计**: 适配不同屏幕尺寸

## 🚀 使用方法

### 1. 启动系统
```bash
cd 系统构建/smart-qa-system/src
python app.py
```

### 2. 访问界面
- 打开浏览器访问: `http://localhost:5000`
- 输入中医相关问题，例如："人参有什么功效？"

### 3. 查看可视化
- 提交问题后，AI回答下方会显示增强信息标签页
- 点击不同标签查看：
  - **📊 知识图谱信息**: 文本格式的知识图谱上下文
  - **🔍 图谱可视化**: 图形化的实体关系展示
  - **🧠 推理路径**: 详细的推理步骤分解

## 📊 数据流程

### 1. 问题处理流程
```
用户问题 → 实体抽取 → 知识图谱查询 → 上下文增强 → 答案生成
    ↓
可视化数据生成 → 推理路径构建 → 前端展示
```

### 2. 后端API响应
```json
{
    "answer": "AI生成的答案",
    "entities": [{"text": "人参", "type": "MED"}],
    "kg_context": "格式化的知识图谱上下文",
    "visualization_data": {
        "nodes": [...],
        "edges": [...],
        "stats": {...}
    },
    "reasoning_path": [
        {
            "step": 1,
            "title": "问题分析",
            "description": "...",
            "details": {...}
        }
    ]
}
```

1. **数据依赖**: 需要Neo4j中有相关的知识图谱数据

3. **浏览器兼容**: 建议使用现代浏览器以获得最佳体验
